Game Clips that play from a link in Discord. Steam. Telegram. Slack. Discord.

Press F9 to save the last 20 seconds, then copy the free public link and paste it in Discord. The Clip plays there with no upload wait and no Vice file-size limit.

Install Vice See how sharing works
Arch-based: yay -S vice-clipper
Other distros: git clone https://github.com/splitshotz/Vice && cd Vice && ./install.sh
NixOS flake: inputs.vice.url = "github:splitshotz/Vice";

On NixOS, add vice.nixosModules.default to your modules and set services.vice.enable = true. Full setup

How it works

Play normally. Press F9 when something happens.

Vice starts at login and keeps the last 20 seconds ready. You do not have to start recording first.

  1. 01

    Vice keeps 20 seconds ready

    It runs in the background while you play, usually using less than one percent of your CPU.

  2. 02

    Press F9

    One press saves a Clip. Double-tap F9 to start a full Session.

  3. 03

    Use the Clip

    Trim or edit it, add it to a Playlist, or copy a public link and send it.

Why use Vice?

Send a Discord link instead of a video file.

The Clip plays in Discord without an upload. Vice also handles recording, editing, and organization.

Free, unlimited sharing

Paste a link. The Clip plays in Discord.

Vice shares the Clip directly from your computer. There is no upload, no Vice file-size limit, and no waiting for the file to finish sending.

No upload No quota or file-size limit.

Performance

Leave Vice running while you play.

Typical CPU use is below one percent. Vice records through gpu-screen-recorder with NVENC or VAAPI on NVIDIA, AMD, and Intel.

<1% Typical CPU use.

Editing

Trim and edit Clips in Vice.

The trimmer cuts a Clip without re-encoding it. The multi-track editor handles video, audio, text, and transitions.

Built in No separate editor required.

Game detection

Vice sorts Clips by game for you.

Vice detects known games, tags Clip filenames, adds them to matching Playlists, and updates your Discord Rich Presence.

Automatic Game tags, Playlists, and Rich Presence.
